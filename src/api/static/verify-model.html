¿Qué debes revisar en DevTools (Pestaña Network)?

  1. Filtro All o Fetch/XHR: Verifica que todas las peticiones apunten únicamente al origen local (/static/vendor/...).
  2. Archivos cargados en la cascada: tf.min.js, coco-ssd.min.js, model.json y los 5 shards binarios (group1-shard1of5 a group1-shard5of5).
  3. Cero peticiones externas: La columna Domain / Host no debe contener storage.googleapis.com, jsdelivr.net, unpkg.com ni ningún otro dominio externo.
  4. Prueba sin conexión (Offline): Puedes seleccionar el perfil Offline en el selector de red de DevTools (o desconectar internet de tu PC) y recargar; el modelo cargará exitosamente 100% en local.
